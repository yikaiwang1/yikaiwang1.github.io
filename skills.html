compact-archive Claude Code plugin

Cheaper long sessions, without losing the history

Every turn sends the whole conversation to the model again, so the longer a session runs, the more each turn costs. Compacting (summarising) the conversation earlier keeps later turns cheap, but people tend to put it off: the full history is gone afterwards, and the summary may drop the wrong details. This plugin removes both worries.

  • Archive before every compaction. A hook copies the full transcript, including subagent transcripts, to a folder of your choice before every compaction, whether you type /compact or it happens automatically.
  • Compact earlier. A setup skill sets a smaller auto-compact window, for example 300k tokens instead of close to the 1M limit.
  • Better summaries. It adds compaction rules to CLAUDE.md: keep the recent work (current task, latest results, files just changed, running jobs) in detail, drop dead ends, and point to the archive for the rest.

In my own long research sessions, compacting at 300k tokens instead of near the 1M limit cut the cost by about 40–46% (simulated at API prices).

Install in Claude Code:

/plugin marketplace add yikaiwang1/claude-compact-archive
/plugin install compact-archive@claude-compact-archive

Then ask Claude to “set up compaction”. Code and documentation on GitHub →

google-extended-setup Claude skill

Gmail and Google Tasks beyond the built-in connectors

Claude’s built-in Gmail and Calendar connectors handle searching, reading, drafting, sending and calendar events well. This skill adds what they do not cover, using small Python scripts and an OAuth token that you create for your own Google account; your mail goes only between your computer and Google. Every capability is documented twice, as a ready-to-run script and as the exact Google API calls behind it, so Claude can rebuild any script from the skill description alone.

TaskBuilt-in Gmail connectorWith this skill
Attach files from your computer Files must be passed as base64 text inside the tool call, which is impractical for real PDFs or figures; replies take no attachments Attaches files straight from disk to new emails, drafts and replies in the same thread (up to Gmail’s 25 MB limit)
Download attachments Shows attachment names, but has no tool to save the file Lists attachments and saves them to a folder
Several Gmail accounts One linked account One token per account; switch with one command
Google Tasks No connector Full control: list, add, edit, complete, reopen, delete
Google Calendar Fully covered Nothing extra needed

Works in Claude Code and Claude Cowork; it needs Python and a one-time Google Cloud setup, which the skill walks you through. Code and documentation on GitHub →
